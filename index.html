Sincronización con la Página de Clientes

Conecta este panel con "Gestión Cliente" de tu sitio público
Tu página pública busca al cliente en una Hoja de Google (ID 1UsNouaSVr...9YIQ) y le muestra su plan, estado y un botón para descargar su recibo. Este panel guarda todo en tu navegador, así que para que el cliente vea su información real, necesitas conectar ambos con un "puente" gratuito de Google (Apps Script). Es un paso único de configuración — abajo tienes el código y las instrucciones.
Usa "Importar / Actualizar Datos en Este Dispositivo" cada vez que abras el panel en un teléfono u otro computador distinto, para traer los clientes, planes, pagos y equipos más recientes guardados en la Hoja.

Copia de Seguridad Local

Descarga un respaldo de todo lo guardado en este dispositivo (clientes, planes, pagos, equipos, usuarios, logs, nodos e historial)
Esta copia se guarda como un archivo .json en tu dispositivo (descárgalo a Drive, correo o donde prefieras). Sirve para recuperar tu información si algo le pasa al navegador o al equipo. "Restaurar" reemplaza TODA la información actual de este dispositivo por la del archivo — úsalo con cuidado, y de ser posible descarga una copia de seguridad actual antes de restaurar una vieja.

Exportar Reportes a Excel

Descarga tus datos en formato .xlsx, listos para abrir en Excel o Google Sheets — útil para tu contador o para llevar tus propios reportes
"Clientes" exporta tu base completa. "Historial de Pagos" exporta todos los pagos registrados (todos los meses). "Cartera Vencida" exporta solo los clientes activos que deben, con los días de mora y el valor pendiente — el reporte que más sirve para cobrar.

Nuevo Pool de IP
Define un rango o lista de IPs; el sistema las ofrecerá al crear clientes, sin repetir las ya asignadas
Al crear o editar un cliente, solo se le ofrecerán las IPs de los pools cuya vereda coincida con la del cliente. Si aplica a varias veredas, sepáralas por coma.
Acepta rangos (192.168.10.2-192.168.10.254 o 192.168.10.2-254), notación CIDR (192.168.10.0/24) o IPs sueltas separadas por coma o salto de línea. Puedes combinar varias líneas.
Haz clic en una IP para reservarla — quedará fuera del selector de clientes pero seguirá contando en el pool. Las que ya tiene un cliente asignado no se pueden reservar (aparecen bloqueadas).
